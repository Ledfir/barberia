# 🎯 Panel de Usuario - Inicio Rápido

## ¿Qué es esto?

Se ha implementado un **panel de usuario completo** para tu barbería con rutas `/login` y `/dashboard`.

---

## 🚀 Comienza en 3 pasos

### 1️⃣ Inicia el servidor
```bash
npm run dev
```

### 2️⃣ Abre el login
Navega a: `http://localhost:5173/login`

### 3️⃣ Accede al panel
Después de autenticarte, haz clic en **"Panel"** en la Navbar

---

## 📍 URLs de Acceso

| Página | URL |
|--------|-----|
| 🏠 Inicio | http://localhost:5173/ |
| 🔐 Login | http://localhost:5173/login |
| 👤 Panel | http://localhost:5173/dashboard |

---

## ✨ Lo que puedes hacer

- ✅ Ver tu perfil (nombre, email, teléfono, fecha de inscripción)
- ✅ Ver tus reservaciones (preparado para integrar con API)
- ✅ Configurar notificaciones
- ✅ Cerrar sesión de forma segura
